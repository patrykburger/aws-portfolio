IAM least privilege

A deploy-only IAM user limited to one S3 bucket and one CloudFront distribution, with tests proving that everything else is denied.

  • IAM
  • Policies
  • Least privilege
  • AWS CLI
What I learned
  • IAM denies by default, so a policy only needs to list what is allowed
  • Bucket-level and object-level actions need different resource ARNs
  • Named CLI profiles keep admin and deploy credentials apart
